## 🎯 概要

このアプリケーションは、学生向けの時間割管理ツールです。CSVファイルから科目データを読み込み、美しいWebインターフェースで時間割を管理できます。

### 主な特徴
- ✨ モダンで美しいデザイン
- 📱 スマートフォン対応（レスポンシブデザイン）
- 🔄 リアルタイム更新
- 📝 科目の追加・削除・詳細表示
- 📊 科目詳細モーダル表示
- 📄 ページネーション機能
- 💾 データの永続化

## 🚀 機能

### 基本機能
- **時間割表示**: 月〜土の6時限分の時間割を表示
- **科目検索**: CSVデータから科目を検索
- **科目追加**: 検索結果から時間割に追加
- **科目詳細**: 科目をクリックして詳細情報を表示
- **科目削除**: 不要な科目を削除

### 検索機能
- **科目名検索**: 科目名で検索
- **曜日・時限検索**: 特定の曜日や時限で検索
- **授業方法検索**: 対面・オンライン等で検索
- **ページネーション**: 大量データの分割表示

### 科目情報
- 教科名
- 曜日・時限
- 教室
- 教員名
- 単位数
- 授業形態
- 科目区分
- 成績評価方法
- キャンパス情報
- URL

## 📖 使い方

### 基本操作

#### 1. 時間割の確認
- ページを開くと、現在の時間割が表示されます
- 科目がある場合は、カラフルなカードで表示されます

#### 2. 科目検索と追加
1. 検索フォームに条件を入力：
   - **科目名**: 科目名の一部を入力
   - **曜日・時限**: 「金」「月3」など
   - **授業方法**: 「対面」「オンライン」など
2. 「検索」ボタンをクリック
3. 検索結果から科目を選択
4. 「時間割に追加」ボタンをクリック
5. 時間割に新しい科目が追加されます

#### 3. 科目の詳細確認
- 時間割の科目カードをクリック
- 詳細情報がモーダルで表示されます
- CSVの全カラム情報を確認できます

#### 4. 科目の削除
- 時間割の科目カードをクリック
- 詳細モーダルで「削除」ボタンをクリック

### 高度な操作

#### 検索のコツ
- **部分一致**: 「数学」で数学関連の科目を検索
- **曜日指定**: 「金」で金曜日の科目のみ検索
- **時限指定**: 「3」で3時限の科目のみ検索
- **組み合わせ**: 「金3」で金曜日3時限の科目を検索

#### ページネーション
- 検索結果が多すぎる場合は、ページ分割で表示
- 最大15件まで表示（それ以上はエラーメッセージ）

#### データの永続化
- 追加した科目は自動的に保存されます
- サーバーを再起動してもデータは保持されます

## 🔧 トラブルシューティング

### よくある問題と解決方法

#### 1. サーバーが起動しない
**エラー**: `ModuleNotFoundError: No module named 'flask'`

**解決方法**:
```bash
pip install flask pandas
```

#### 2. 検索でエラーが発生
**エラー**: 「検索中にエラーが発生しました」

**解決方法**:
- 検索条件を絞り込む（例：「金」だけではなく「金3」など）
- サーバーログを確認して詳細なエラーを確認

#### 3. 科目が追加されない
**原因**: 時限データの形式問題

**解決方法**:
- 全角数字が含まれている場合は半角に変換
- 配列形式のデータは自動的に処理されます

#### 4. ポートが使用中
**エラー**: `Address already in use`

**解決方法**:
```bash
# 別のポートで起動
python app.py --port 5001
```

#### 5. データベースエラー
**エラー**: `database is locked`

**解決方法**:
- 他のプログラムでデータベースを使用していないか確認
- サーバーを再起動

### デバッグ方法

#### 1. コンソールログの確認
ブラウザの開発者ツール（F12）を開いて、コンソールタブでエラーメッセージを確認

#### 2. サーバーログの確認
